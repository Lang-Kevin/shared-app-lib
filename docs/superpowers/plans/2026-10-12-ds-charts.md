# Chart toolkit (SP3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to carry this plan out task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the lib chart toolkit as release 0.6.0. It contains:
- pure, JVM-tested viewport/tick/scale/geometry math;
- token-only Canvas primitives;
- `LineChart` (zone chart with target band, GOAL badge, dashed accent mean line, markers, last point, scrubber and tooltip, time axis);
- `TrendChart` (optional band), `BarChart`, `ZoneDistributionBar` and `TimeInZoneSection` (also used as the hr History mini zone bar, spec §7.2).

**Architecture:** Three layers in `com.kevin.shared.ui.chart`:
1. **Pure model/math** (`ChartViewport`, `ChartTicks`, `ChartMath`, `ChartGeometry`, `ChartModels`). No Compose. Every function has a JUnit4 test.
2. **Drawing primitives** (`ChartDraw.kt`). `DrawScope` extensions that take resolved `ChartColors` and px values.
3. **Thin composables** (`LineChart`, `TrendChart`, `BarChart`, `TimeInZone`). They only wire layer 1 to layer 2.

X is always in data units (seconds or sample index). `ChartViewport.toWindow(total)` (Detail) and `LiveWindow.toWindow(total)` (Live) both produce a `ClosedFloatingPointRange<Float>` window, so one `LineChart` replaces hr's Live/Detail fork (`LiveScreen.kt:394-405`). Colors come only from `MaterialTheme.colorScheme` + `AppTheme.colors` via `ChartDefaults.colors()`. Text is drawn with `TextMeasurer` + `labelSmall`.

**Tech Stack:** Kotlin 2.4.20, Compose BOM 2026.05.01 (ui, material3, foundation), JUnit 4.13.2. compileSdk 37, minSdk 26.

**Spec:** `docs/superpowers/specs/2026-10-11-design-system-foundation-design.md`, roadmap row 3, §7.2 (History mini zone bar, Stats), §7.4 (no axis zone strip; the GOAL badge stays). The binding mockup is `docs/design/mockups/00-final-screens.html`:

## Review Focus (for @reviewer on every task)

1. **Empty data.**
   - Size-0 series, all-NaN series, empty zones and empty durations/values never crash and never divide by zero.
   - Ranges fall back to `0..1`.
   - Nothing is drawn, and there is no last point.
2. **Single point.**
   - `visibleIndices` returns `0..0` and `decimate` returns one point.
   - `drawPolyline` turns an isolated point into a dot.
   - `trendX` centers when `n <= 1`.
   - A window with span 0 maps to the plot center.
3. **All-equal values.**
   - The dynamic zone range pads at least ±1.
   - The trend range pads ±max(1, |v|)·10 %.
   - Equal bars are all full height; equal durations give equal segments.
4. **Extreme zoom.**
   - The `ChartViewport` minSpan floor `1e-4` holds, as do the `LiveWindow` min/max parameters.
   - A tooltip wider than the plot is pinned left.
   - Labels are clamped inside `[0, width]`.
   - Decimation stays at most `maxPoints + 2` and anchors chunks at absolute indices (no shimmer while scrolling).
5. **NaN/gaps.**
   - A NaN y breaks the path.
   - A decimation chunk containing a NaN becomes a gap.
   - A scrubber on a NaN sample draws the line only, with no dot or tooltip.
   - NaN factor/delta/window inputs are no-ops or return empty.
   - Tokens only: both checkers exit 0.

- [ ] **Step 4: Write `ChartViewport.kt`.**
  ```kotlin
  package com.kevin.shared.ui.chart

  import kotlin.math.ceil
  import kotlin.math.floor
  import kotlin.math.max
  import kotlin.math.min
  import kotlin.math.roundToInt

  /**
   * Visible X range of a chart as fractions (0..1) of the full data width (Detail charts).
   * Pure Kotlin, JVM-testable. Port of hr `ui/shared/ChartViewport.kt:13-76` (fe31536).
   */
  data class ChartViewport(val start: Float = 0f, val end: Float = 1f) {

      val span: Float get() = end - start

      /** true when the whole data range is visible. */
      val isFull: Boolean get() = start <= EPS && end >= 1f - EPS

      /**
       * Zooms by [factor] (>1 = in). [anchor] (0..1) is the position inside the visible width;
       * the data point under it stays there (except when clamped at 0/1).
       */
      fun zoomBy(factor: Float, anchor: Float, minSpan: Float): ChartViewport {
          if (factor <= 0f || factor.isNaN() || factor.isInfinite()) return this
          val a = anchor.coerceIn(0f, 1f)
          val newSpan = (span / factor).coerceIn(minSpan.coerceIn(TINY, 1f), 1f)
          val focus = start + a * span
          val newStart = (focus - a * newSpan).coerceIn(0f, 1f - newSpan)
          return snapped(newStart, newSpan)
      }

      /**
       * Pans by [deltaFraction] of the visible width. Positive = content moves right, i.e. earlier
       * data becomes visible (like swiping right). The span is kept.
       */
      fun panBy(deltaFraction: Float): ChartViewport {
          val s = span
          val newStart = (start - deltaFraction * s).coerceIn(0f, 1f - s)
          return snapped(newStart, s)
      }

      /** Snaps to the exact edges so float noise never yields "almost full". */
      private fun snapped(start: Float, span: Float): ChartViewport {
          var s = start
          var e = start + span
          val atEnd = e > 1f - EPS
          if (atEnd) { e = 1f; s = 1f - span }
          if (s < EPS) { s = 0f; if (!atEnd) e = span }
          return ChartViewport(s, e)
      }

      /** Position of [fraction] (data range) inside the visible window; may lie outside 0..1. */
      fun mapX(fraction: Float): Float = (fraction - start) / span

      /**
       * Indices of samples whose fraction i/(size-1) lies in [start, end], plus one neighbour on
       * each side so the line reaches the edge.
       */
      fun visibleIndexRange(size: Int): IntRange {
          if (size <= 0) return IntRange.EMPTY
          if (size == 1) return 0..0
          val n = (size - 1).toFloat()
          val first = ceil(start * n - 1e-4f).toInt() - 1
          val last = floor(end * n + 1e-4f).toInt() + 1
          val lo = first.coerceIn(0, size - 1)
          val hi = last.coerceIn(0, size - 1)
          return if (lo <= hi) lo..hi else IntRange.EMPTY
      }

      /** Visible window in data units for data spanning 0..[totalX] (e.g. session seconds). */
      fun toWindow(totalX: Float): ClosedFloatingPointRange<Float> {
          val t = if (totalX.isFinite() && totalX > 0f) totalX else 0f
          return (start * t)..(end * t)
      }

      companion object {
          val Full = ChartViewport()
          private const val EPS = 1e-4f
          private const val TINY = 1e-4f
      }
  }

  /**
   * Index of the sample under [fraction] (0..1 across the visible plot width), mapped linearly onto
   * range.first..range.last, rounded and clamped; null for an empty range or NaN.
   */
  fun nearestIndex(fraction: Float, range: IntRange): Int? {
      if (range.isEmpty()) return null
      if (fraction.isNaN()) return null
      val f = fraction.coerceIn(0f, 1f)
      val idx = range.first + (f * (range.last - range.first)).roundToInt()
      return idx.coerceIn(range.first, range.last)
  }

  /**
   * Live window in samples (hr: 1 sample ≈ 1 s). [windowSeconds] is the (float) width, [anchorEnd]
   * the absolute index of the right edge when scrolled back; null = follows the newest sample.
   * Because the anchor is absolute, the view stays put while samples are appended, and many small
   * pan/zoom steps keep sub-sample precision. Port of hr `ui/shared/ChartViewport.kt:96-151`.
   */
  data class LiveWindow(val windowSeconds: Float = DEFAULT.toFloat(), val anchorEnd: Float? = null) {

      val isFollowing: Boolean get() = anchorEnd == null

      /** Visible sample indices for [total] samples; empty when total <= 0. */
      fun visibleRange(total: Int): IntRange {
          if (total <= 0) return IntRange.EMPTY
          val w = windowSeconds.roundToInt().coerceIn(1, max(1, total))
          val end = if (anchorEnd == null) total - 1
          else anchorEnd.roundToInt().coerceIn(min(w - 1, total - 1), total - 1)
          val start = (end - w + 1).coerceAtLeast(0)
          return start..end
      }

      /**
       * Zooms by [factor] (>1 = in) around [anchor] (0..1 of the visible width); the sample under
       * the anchor stays fixed. When everything is visible only the stored width changes.
       * [minWindow]/[maxWindow] bound the width (defaults: hr's 30 s / 6 h).
       */
      fun zoomBy(
          factor: Float,
          anchor: Float,
          total: Int,
          minWindow: Float = MIN.toFloat(),
          maxWindow: Float = MAX_WINDOW,
      ): LiveWindow {
          if (factor <= 0f || factor.isNaN() || factor.isInfinite()) return this
          val a = anchor.coerceIn(0f, 1f)
          val effW = min(windowSeconds, total.toFloat()).coerceAtLeast(1f)
          val newW = (effW / factor).coerceAtLeast(minWindow)
          if (newW >= total) {
              return copy(windowSeconds = max(newW, windowSeconds).coerceAtMost(maxWindow))
          }
          val lastIdx = total - 1f
          val currentEnd = (anchorEnd ?: lastIdx).coerceIn(min(effW - 1f, lastIdx), lastIdx)
          val anchorSample = currentEnd - (1f - a) * (effW - 1f)
          val newEnd = anchorSample + (1f - a) * (newW - 1f)
          return when {
              isFollowing && a >= 0.999f -> LiveWindow(newW, null)
              newEnd >= lastIdx -> LiveWindow(newW, null)
              else -> LiveWindow(newW, newEnd.coerceAtLeast(min(newW - 1f, lastIdx)))
          }
      }

      /** Pans by [deltaSeconds]; positive = further into the past. */
      fun panBy(deltaSeconds: Float, total: Int): LiveWindow {
          if (total <= 0 || deltaSeconds.isNaN()) return this
          val effW = min(windowSeconds, total.toFloat()).coerceAtLeast(1f)
          val lastIdx = total - 1f
          val base = anchorEnd ?: lastIdx
          val newEnd = (base - deltaSeconds).coerceAtLeast(min(effW - 1f, lastIdx))
          // Snap to live only when scrolling back towards it; moving away from the live edge must
          // let many small steps (< 0.5 s) add up.
          return if (newEnd >= lastIdx || (deltaSeconds <= 0f && newEnd >= lastIdx - 0.5f)) copy(anchorEnd = null)
          else copy(anchorEnd = newEnd)
      }

      /** Visible window in index units (x = sample index); 0..0 when empty. */
      fun toWindow(total: Int): ClosedFloatingPointRange<Float> {
          val r = visibleRange(total)
          return if (r.isEmpty()) 0f..0f else r.first.toFloat()..r.last.toFloat()
      }

      companion object {
          const val DEFAULT = 120
          const val MIN = 30
          const val MAX_WINDOW = 21600f
      }
  }
  ```

  package com.kevin.shared.ui.chart

  import java.util.Locale
  import kotlin.math.ceil
  import kotlin.math.floor

  /** "Nice" time-axis steps in seconds. */
  private val NICE_STEPS_SEC = intArrayOf(5, 10, 15, 30, 60, 120, 300, 600, 900, 1800, 3600, 7200)

  /**
   * Tick positions (seconds, multiples of the step) within [fromSec]..[toSec] inclusive, using the
   * smallest nice step that yields at most [maxTicks] ticks. Port of hr `ui/shared/ChartTicks.kt:7-38`.
   */
  internal fun timeTicks(fromSec: Float, toSec: Float, maxTicks: Int = 5): List<Float> {
      if (fromSec.isNaN() || toSec.isNaN() || toSec <= fromSec) return emptyList()
      val limit = maxTicks.coerceAtLeast(1)
      val steps = NICE_STEPS_SEC
      var chosen = steps.last()
      for (s in steps) {
          if (countTicks(fromSec, toSec, s) <= limit) { chosen = s; break }
      }
      return ticksFor(fromSec, toSec, chosen).let { if (it.size > limit) it.take(limit) else it }
  }

  private fun firstMultiple(fromSec: Float, step: Int): Long = ceil(fromSec / step).toLong()
  private fun lastMultiple(toSec: Float, step: Int): Long = floor(toSec / step).toLong()

  private fun countTicks(fromSec: Float, toSec: Float, step: Int): Int {
      val n = lastMultiple(toSec, step) - firstMultiple(fromSec, step) + 1
      return n.coerceIn(0L, Int.MAX_VALUE.toLong()).toInt()
  }

  private fun ticksFor(fromSec: Float, toSec: Float, step: Int): List<Float> {
      val a = firstMultiple(fromSec, step)
      val b = lastMultiple(toSec, step)
      if (b < a) return emptyList()
      return (a..b).map { (it * step).toFloat() }
  }

  /** "m:ss" below one hour (e.g. "0:30", "12:05"), "h:mm:ss" from one hour. hr `ChartTicks.kt:41-47`. */
  internal fun formatTickLabel(sec: Float): String {
      val total = if (sec.isNaN() || sec < 0f) 0L else Math.round(sec).toLong()
      val h = total / 3600
      val m = (total % 3600) / 60
      val s = total % 60
      return if (h > 0) String.format(Locale.ROOT, "%d:%02d:%02d", h, m, s)
      else String.format(Locale.ROOT, "%d:%02d", m, s)
  }

  /**
   * Indices of at most [maxLabels] category labels, evenly spaced and anchored at the last
   * (current) item: count 8, max 4 -> [1, 3, 5, 7]. Empty for count <= 0.
   */
  internal fun labelIndices(count: Int, maxLabels: Int): List<Int> {
      if (count <= 0) return emptyList()
      val limit = maxLabels.coerceAtLeast(1)
      val step = (count - 1) / limit + 1 // ceil(count / limit) without overflow for limit = Int.MAX_VALUE
      return (count - 1 downTo 0 step step).toList().asReversed()
  }

  ```kotlin
  package com.kevin.shared.ui.chart

  import kotlin.math.abs
  import kotlin.math.max

  /** Static zone scale: this far below the lowest and above the highest zone bound (hr: 8 bpm). */
  internal const val ZONE_SCALE_PAD: Float = 8f

  /**
   * Y range of the zone chart (hr `TrainingUi.kt:92-108`, `LiveScreen.kt:445-466`).
   * - static ([dynamic] false) with zones: lowest lo − [zonePad] .. highest hi + [zonePad], widened to
   *   include finite data;
   * - otherwise finite values plus the target zone's bounds, padded by max(10 % of span, 1);
   * - nothing finite and no target: 0..1.
   */
  internal fun zoneChartRange(
      visibleYs: List<Float>,
      zones: List<ChartZone>,
      targetZone: Int?,
      dynamic: Boolean,
      zonePad: Float = ZONE_SCALE_PAD,
  ): ClosedFloatingPointRange<Float> {
      var lo = Float.POSITIVE_INFINITY
      var hi = Float.NEGATIVE_INFINITY
      for (y in visibleYs) if (y.isFinite()) {
          if (y < lo) lo = y
          if (y > hi) hi = y
      }
      if (!dynamic && zones.isNotEmpty()) {
          return minOf(zones.minOf { it.lo } - zonePad, lo)..maxOf(zones.maxOf { it.hi } + zonePad, hi)
      }
      val target = zones.firstOrNull { it.number == targetZone }
      if (target != null) {
          lo = minOf(lo, target.lo)
          hi = maxOf(hi, target.hi)
      }
      if (lo > hi) return 0f..1f
      val pad = max((hi - lo) * 0.1f, 1f)
      return (lo - pad)..(hi + pad)
  }

  /**
   * Y range of TrendChart (hr `TrendChart.kt:29-45`): finite values plus [band] and [reference],
   * padded by 10 % of the span; flat data by max(1, |v|)·10 %; nothing finite: 0..1.
   */
  internal fun trendRange(
      values: List<Float>,
      band: ClosedFloatingPointRange<Float>? = null,
      reference: Float? = null,
  ): ClosedFloatingPointRange<Float> {
      var lo = Float.POSITIVE_INFINITY
      var hi = Float.NEGATIVE_INFINITY
      fun take(v: Float) {
          if (v.isFinite()) {
              if (v < lo) lo = v
              if (v > hi) hi = v
          }
      }
      values.forEach { take(it) }
      if (band != null) { take(band.start); take(band.endInclusive) }
      if (reference != null) take(reference)
      if (lo > hi) return 0f..1f
      val span = hi - lo
      val pad = if (span > 0f) span * 0.1f else max(1f, abs(lo)) * 0.1f
      return (lo - pad)..(hi + pad)
  }

  /**
   * Indices whose x lies in [from]..[to] plus one neighbour per side (binary search; x ascending).
   * A window between two samples yields both; a window beyond the data yields the edge sample.
   */
  internal fun visibleIndices(size: Int, from: Float, to: Float, xAt: (Int) -> Float): IntRange {
      if (size <= 0 || from.isNaN() || to.isNaN() || to < from) return IntRange.EMPTY
      var lo = 0
      var hi = size
      while (lo < hi) {
          val mid = (lo + hi) ushr 1
          if (xAt(mid) < from) lo = mid + 1 else hi = mid
      }
      val first = lo
      hi = size
      while (lo < hi) {
          val mid = (lo + hi) ushr 1
          if (xAt(mid) <= to) lo = mid + 1 else hi = mid
      }
      val lastIncl = lo - 1
      val a = (first - 1).coerceIn(0, size - 1)
      val b = (lastIncl + 1).coerceIn(0, size - 1)
      return if (a <= b) a..b else IntRange.EMPTY
  }

  /**
   * [range] reduced to about [maxPoints] points (hr `LiveScreen.kt:589-616`): means over chunks
   * anchored at absolute multiples of the chunk size (stable while a live window scrolls), the
   * last sample of [range] always raw. A chunk with a non-finite y becomes a NaN point (keeps gaps).
   * At most maxPoints + 2 points.
   */
  internal fun decimate(
      range: IntRange,
      maxPoints: Int,
      xAt: (Int) -> Float,
      yAt: (Int) -> Float,
  ): List<ChartPoint> {
      if (range.isEmpty()) return emptyList()
      val n = range.last - range.first + 1
      val limit = maxPoints.coerceAtLeast(2)
      if (n <= limit) return range.map { ChartPoint(xAt(it), yAt(it)) }
      val chunk = (n + limit - 1) / limit
      val body = range.last - 1
      val out = ArrayList<ChartPoint>(limit + 2)
      var c = (range.first / chunk) * chunk
      while (c <= body) {
          val a = maxOf(c, range.first)
          val b = minOf(c + chunk - 1, body)
          var sx = 0.0
          var sy = 0.0
          var gap = false
          for (i in a..b) {
              val y = yAt(i)
              if (!y.isFinite()) gap = true else sy += y
              sx += xAt(i)
          }
          val cnt = b - a + 1
          out += ChartPoint((sx / cnt).toFloat(), if (gap) Float.NaN else (sy / cnt).toFloat())
          c += chunk
      }
      out += ChartPoint(xAt(range.last), yAt(range.last))
      return out
  }

  /** Index of the last finite y, or null. */
  internal fun lastFiniteIndex(size: Int, yAt: (Int) -> Float): Int? {
      for (i in size - 1 downTo 0) if (yAt(i).isFinite()) return i
      return null
  }
  ```

  package com.kevin.shared.ui.chart

  import kotlin.math.abs

  /**
   * Position of [xPx] in a plot starting at [left] with [width] px, as 0..1 (clamped); 0 for an
   * empty plot or NaN. Charts here draw edge to edge, so apps pass `plotFraction(x, 0f, widthPx)`
   * as zoom anchor and scrub fraction (hr `LiveScreen.kt:256-293` used a left gutter).
   */
  fun plotFraction(xPx: Float, left: Float, width: Float): Float {
      if (!(width > 0f) || xPx.isNaN()) return 0f
      return ((xPx - left) / width).coerceIn(0f, 1f)
  }

  /** Data x to px; a zero-span window maps to the plot center. */
  internal fun xToPx(x: Float, window: ClosedFloatingPointRange<Float>, left: Float, width: Float): Float {
      val span = window.endInclusive - window.start
      if (!(span > 0f)) return left + width / 2f
      return left + (x - window.start) / span * width
  }

  /** Data y to px (up = larger); a flat range maps to the vertical center. */
  internal fun yToPx(y: Float, range: ClosedFloatingPointRange<Float>, top: Float, height: Float): Float {
      val span = range.endInclusive - range.start
      if (!(span > 0f)) return top + height / 2f
      return top + (1f - (y - range.start) / span) * height
  }

  /** Plot fraction (clamped 0..1) to data x inside [window]. */
  internal fun fractionToX(fraction: Float, window: ClosedFloatingPointRange<Float>): Float =
      window.start + fraction.coerceIn(0f, 1f) * (window.endInclusive - window.start)

  /** Index whose x is nearest to [x] (x ascending, binary search); ties pick the earlier sample. */
  internal fun nearestIndexByX(size: Int, x: Float, xAt: (Int) -> Float): Int? {
      if (size <= 0 || x.isNaN()) return null
      var lo = 0
      var hi = size - 1
      while (lo < hi) {
          val mid = (lo + hi) ushr 1
          if (xAt(mid) < x) lo = mid + 1 else hi = mid
      }
      if (lo > 0 && abs(xAt(lo - 1) - x) <= abs(xAt(lo) - x)) return lo - 1
      return lo
  }

  /** Left edge of a tooltip of [width] centered on [anchorX], kept inside [minX]..[maxX]. */
  internal fun tooltipLeft(anchorX: Float, width: Float, minX: Float, maxX: Float): Float {
      val maxLeft = maxX - width
      if (maxLeft <= minX) return minX
      return (anchorX - width / 2f).coerceIn(minX, maxLeft)
  }

  /** x of trend point [i] of [n] across [left]..[left]+[width]; a single point is centered. */
  internal fun trendX(i: Int, n: Int, left: Float, width: Float): Float =
      if (n <= 1) left + width / 2f else left + i * width / (n - 1)

  /** Horizontal segment of a stacked bar: [index] into the input list. */
  internal data class Segment(val index: Int, val left: Float, val width: Float)

  /**
   * Stacked time-in-zone segments: zones with duration <= 0 are skipped, [gap] only between drawn
   * segments (dropped if it doesn't fit), the last segment ends exactly at [width].
   */
  internal fun zoneSegments(durations: List<Long>, width: Float, gap: Float): List<Segment> {
      val drawn = durations.indices.filter { durations[it] > 0L }
      if (drawn.isEmpty() || !(width > 0f)) return emptyList()
      val total = drawn.sumOf { durations[it].toDouble() }
      val wantGap = gap.coerceAtLeast(0f)
      val g = if (width - wantGap * (drawn.size - 1) > 0f) wantGap else 0f
      val avail = width - g * (drawn.size - 1)
      val out = ArrayList<Segment>(drawn.size)
      var left = 0f
      drawn.forEachIndexed { k, idx ->
          val w = if (k == drawn.lastIndex) width - left
          else (avail * durations[idx].toDouble() / total).toFloat()
          out += Segment(idx, left, w)
          left += w + g
      }
      return out
  }

  /** Bar rectangle in px, origin top-left of the plot. */
  internal data class BarRect(val left: Float, val top: Float, val width: Float, val height: Float)

  /**
   * Equal-width bars over [width] with [gap] between them (dropped if it doesn't fit), heights
   * relative to the largest finite positive value; zero/negative/NaN and an all-zero set give 0.
   */
  internal fun barGeometry(values: List<Float>, width: Float, height: Float, gap: Float): List<BarRect> {
      val n = values.size
      if (n == 0 || !(width > 0f)) return emptyList()
      var g = gap.coerceAtLeast(0f)
      var barW = (width - g * (n - 1)) / n
      if (barW <= 0f) {
          g = 0f
          barW = width / n
      }
      var max = 0f
      for (v in values) if (v.isFinite() && v > max) max = v
      return values.mapIndexed { i, v ->
          val h = if (max > 0f && v.isFinite() && v > 0f) v / max * height else 0f
          BarRect(i * (barW + g), height - h, barW, h)
      }
  }

  /** Polyline through [points] (px). A NaN coordinate breaks the line; an isolated point becomes a dot. */
  internal fun DrawScope.drawPolyline(points: List<Offset>, color: Color, strokePx: Float) {
      val path = Path()
      var run = 0
      var single = Offset.Zero
      for (p in points) {
          if (p.x.isNaN() || p.y.isNaN()) {
              if (run == 1) drawCircle(color, strokePx, single)
              run = 0
              continue
          }
          if (run == 0) {
              path.moveTo(p.x, p.y)
              single = p
          } else {
              path.lineTo(p.x, p.y)
          }
          run++
      }
      if (run == 1) drawCircle(color, strokePx, single)
      drawPath(path, color, style = Stroke(width = strokePx, cap = StrokeCap.Round, join = StrokeJoin.Round))
  }

   * - Two+ fingers: [onZoom] (x scale, centroid in px) and [onPan] (dx in px).
   * - One finger: only when [panEnabled]; consumed only after horizontal touch slop, vertical
   *   movement is not consumed (a parent verticalScroll keeps working).
   * - Double tap: [onDoubleTap] (x in px).
   * - Long press + drag: [onScrub] (x in px, null = ended). No panning while scrubbing.
   * Convert px with [plotFraction] (charts in this package draw edge to edge).
   */
  fun Modifier.chartZoomPan(
      panEnabled: () -> Boolean,
      onZoom: (factor: Float, anchorX: Float) -> Unit,
      onPan: (dxPx: Float) -> Unit,
      onDoubleTap: (x: Float) -> Unit,
      onScrub: ((x: Float?) -> Unit)? = null,
  ): Modifier = composed {
      val panEnabledState by rememberUpdatedState(panEnabled)
      val onZoomState by rememberUpdatedState(onZoom)
      val onPanState by rememberUpdatedState(onPan)
      val onDoubleTapState by rememberUpdatedState(onDoubleTap)
      val onScrubState by rememberUpdatedState(onScrub)
      val scrubbing = remember { BooleanArray(1) }
      val scrubEnabled = onScrub != null

      this
          .pointerInput(Unit) {
              awaitEachGesture {
                  awaitFirstDown(requireUnconsumed = false)
                  var accX = 0f
                  var accY = 0f
                  var panning = false
                  var wasMulti = false
                  while (true) {
                      val event = awaitPointerEvent()
                      if (event.changes.none { it.pressed }) break
                      if (scrubbing[0]) {
                          // Scrubbing: no pan/zoom; reset state so a new gesture starts clean.
                          accX = 0f
                          accY = 0f
                          continue
                      }
                      val pressedCount = event.changes.count { it.pressed }
                      if (pressedCount >= 2) {
                          val zoom = event.calculateZoom()
                          val centroid = event.calculateCentroid()
                          val pan = event.calculatePan()
                          if (zoom != 1f && centroid != Offset.Unspecified) onZoomState(zoom, centroid.x)
                          if (pan.x != 0f) onPanState(pan.x)
                          event.changes.forEach { if (it.positionChange() != Offset.Zero) it.consume() }
                          panning = true
                          wasMulti = true
                      } else if (panEnabledState()) {
                          if (wasMulti) {
                              wasMulti = false
                              accX = 0f
                              accY = 0f
                          }
                          val change = event.changes.firstOrNull { it.pressed } ?: break
                          val delta = change.positionChange()
                          if (panning) {
                              if (delta.x != 0f) onPanState(delta.x)
                              change.consume()
                          } else {
                              accX += delta.x
                              accY += delta.y
                              val slop = viewConfiguration.touchSlop
                              if (abs(accX) > slop && abs(accX) > abs(accY)) {
                                  panning = true
                                  change.consume()
                              } else if (abs(accY) > slop) {
                                  break // vertical: leave the gesture to the parent
                              }
                          }
                      } else {
                          // Pan not allowed: ignore one-finger gestures (don't consume, so a parent
                          // verticalScroll stays usable) and wait for another finger.
                          if (wasMulti) {
                              wasMulti = false
                              panning = false
                              accX = 0f
                              accY = 0f
                          }
                      }
                  }
              }
          }
          .pointerInput(Unit) {
              detectTapGestures(onDoubleTap = { onDoubleTapState(it.x) })
          }
          .then(
              if (scrubEnabled) Modifier.pointerInput(Unit) {
                  detectDragGesturesAfterLongPress(
                      onDragStart = {
                          scrubbing[0] = true
                          onScrubState?.invoke(it.x)
                      },
                      onDrag = { change, _ ->
                          change.consume()
                          onScrubState?.invoke(change.position.x)
                      },
                      onDragEnd = {
                          scrubbing[0] = false
                          onScrubState?.invoke(null)
                      },
                      onDragCancel = {
                          scrubbing[0] = false
                          onScrubState?.invoke(null)
                      },
                  )
              } else Modifier,
          )
  }
